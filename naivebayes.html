Naive Bayes Algorithm

Probability Based Machine Learning Algorithm

1. What is Naive Bayes?

Naive Bayes is a supervised machine learning algorithm used mainly for classification tasks. It is based on probability and uses Bayes’ theorem to predict the class of a given data point.

The term "Naive" comes from the assumption that the features in the dataset are independent of each other. Although this assumption is rarely true in real life, the algorithm still works surprisingly well in many applications.

Example: Email spam filtering where the algorithm predicts whether an email is spam based on certain words.

3. Types of Naive Bayes

  • Gaussian Naive Bayes – Used for continuous data.
  • Multinomial Naive Bayes – Used for text classification.
  • Bernoulli Naive Bayes – Used for binary features.

4. Advantages

  • Fast and simple algorithm
  • Works well with large datasets
  • Effective for text classification
  • Requires less training data

5. Applications

  • Email spam detection
  • Sentiment analysis
  • News classification
  • Document categorization
