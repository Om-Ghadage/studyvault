Naive Bayes Classification

Machine Learning Notes

1. Introduction

Naive Bayes is a supervised machine learning algorithm based on Bayes' Theorem. It is mainly used for classification problems like spam detection and text classification.

2. Bayes Theorem

P(A|B) = (P(B|A) × P(A)) / P(B)

Where:

  • P(A|B) = Posterior probability
  • P(B|A) = Likelihood
  • P(A) = Prior probability
  • P(B) = Evidence

3. Why it is called "Naive"

The algorithm assumes that all features are independent of each other, which is a very simple (naive) assumption.

4. Types of Naive Bayes

  • Gaussian Naive Bayes
  • Multinomial Naive Bayes
  • Bernoulli Naive Bayes

5. Advantages

  • Fast and simple
  • Works well with large datasets
  • Good for text classification

6. Disadvantages

  • Assumes feature independence
  • Less accurate if assumption is violated

7. Applications

  • Email spam filtering
  • Sentiment analysis
  • Document classification
  • Recommendation systems
