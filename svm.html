Support Vector Machine (SVM)

Machine Learning Notes

1. Introduction

Support Vector Machine (SVM) is a supervised machine learning algorithm used for classification and regression. It finds the best boundary called a hyperplane that separates different classes of data.

2. Key Concepts

  • Hyperplane – Decision boundary separating classes
  • Support Vectors – Data points closest to the boundary
  • Margin – Distance between hyperplane and support vectors

3. How SVM Works

  1. Plot data points in space
  2. Find the best separating line or hyperplane
  3. Maximize the margin between classes
  4. Classify new data based on the hyperplane

4. Mathematical Representation

Hyperplane equation: w.x + b = 0

5. Advantages

  • Works well with high-dimensional data
  • Effective in complex datasets
  • Good accuracy

6. Disadvantages

  • Slow for very large datasets
  • Difficult to choose kernel function
