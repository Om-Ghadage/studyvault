Logistic Regression

Machine Learning Classification Algorithm

1. What is Logistic Regression?

Logistic Regression is a supervised machine learning algorithm used for classification problems. Unlike linear regression which predicts continuous values, logistic regression predicts the probability of a categorical outcome.

It is commonly used when the dependent variable has two possible outcomes such as Yes/No, True/False, or 0/1. The algorithm estimates the probability that a given input belongs to a certain class.

Logistic regression uses a mathematical function called the sigmoid function to map predicted values to probabilities between 0 and 1. Based on this probability, the model assigns the input to a particular class.

Example: Predicting whether an email is spam (1) or not spam (0).

2. Logistic Function (Sigmoid Curve)

The logistic regression model uses a sigmoid function to convert linear predictions into probabilities between 0 and 1.

The logistic regression equation is:

p(x)=\frac{1}{1+e^{-x}}

This function produces an S-shaped curve which helps in separating the data into two classes based on probability.

3. Working of Logistic Regression

  • Step 1: Collect and prepare the dataset.
  • Step 2: Apply the logistic regression model to the data.
  • Step 3: Calculate probability using the sigmoid function.
  • Step 4: Set a threshold value (usually 0.5).
  • Step 5: If probability > 0.5 → Class 1, otherwise Class 0.

The algorithm adjusts its parameters during training to minimize prediction errors and improve classification accuracy.

4. Types of Logistic Regression

  • Binary Logistic Regression – Used when there are two possible outcomes.
  • Multinomial Logistic Regression – Used when there are more than two categories.
  • Ordinal Logistic Regression – Used when categories have a natural order.

5. Real World Applications

  • Email spam detection
  • Medical disease prediction
  • Credit card fraud detection
  • Customer churn prediction
  • Marketing response prediction
  • Admission prediction in universities

Because logistic regression is simple, efficient, and easy to interpret, it is widely used in real-world classification problems.
