Logistic Regression

Machine Learning Notes

1. Introduction

Logistic Regression is a supervised machine learning algorithm used for classification problems. It predicts the probability that an input belongs to a particular category.

2. Key Idea

Unlike Linear Regression, Logistic Regression predicts the probability of a class using a sigmoid function.

Sigmoid Function: P = 1 / (1 + e^(-z))

3. How Logistic Regression Works

  1. Take input features
  2. Calculate weighted sum
  3. Apply sigmoid function
  4. Convert probability into class label

4. Mathematical Model

z = b0 + b1x1 + b2x2 + ... + bnxn P = 1 / (1 + e^-z)

If P > 0.5 → Class 1 If P < 0.5 → Class 0

5. Types of Logistic Regression

  • Binary Logistic Regression – Two classes (Yes/No)
  • Multinomial Logistic Regression – More than two classes
  • Ordinal Logistic Regression – Ordered categories

6. Advantages

  • Simple and easy to implement
  • Works well for binary classification
  • Fast training process
  • Interpretable results

7. Disadvantages

  • Not suitable for complex relationships
  • Assumes linear relationship between variables
  • Less accurate for large complex datasets

8. Applications

  • Spam email detection
  • Disease prediction
  • Credit risk analysis
  • Customer churn prediction
  • Marketing response prediction
