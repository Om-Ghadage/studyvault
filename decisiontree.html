Decision Tree - Machine Learning Notes

Simple Explanation of Decision Tree Algorithm

1. Introduction

A Decision Tree is a supervised machine learning algorithm used for classification and regression problems. It works like a tree structure where decisions are made based on conditions.

2. Structure of a Decision Tree

  • Root Node – Starting point of the tree
  • Decision Nodes – Nodes where data splits based on conditions
  • Leaf Nodes – Final output or prediction
Age? / \ <30 >30 / \ Student? Income? / \ / \ Yes No High Low Buy Not Buy Not

3. How Decision Trees Work

  1. Start with the full dataset.
  2. Select the best feature to split the data.
  3. Create subsets based on the feature.
  4. Repeat the process for each subset.
  5. Stop when data is fully classified or depth limit is reached.

4. Splitting Criteria

Entropy

Measures impurity in the dataset.

Entropy = - Σ (p * log2(p))

Information Gain

Information Gain = Entropy(parent) - Entropy(children)

Gini Index

Gini = 1 - Σ (p²)

5. Types of Decision Trees

  • Classification Tree – Output is a category (Yes/No, Spam/Not Spam)
  • Regression Tree – Output is a numerical value (price, score)

6. Advantages

  • Easy to understand and visualize
  • Handles numerical and categorical data
  • Requires little data preprocessing
  • Works for classification and regression

7. Disadvantages

  • Can easily overfit
  • Sensitive to small data changes
  • Can become very complex

8. Applications

  • Medical diagnosis
  • Fraud detection
  • Customer segmentation
  • Credit risk analysis
  • Recommendation systems
