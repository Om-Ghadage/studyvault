K-Nearest Neighbors (KNN) Algorithm

Machine Learning Notes

1. Introduction

K-Nearest Neighbors (KNN) is a supervised machine learning algorithm used for classification and regression. It works by finding the nearest data points (neighbors) to a new input and predicting the output based on those neighbors.

2. Basic Idea

The algorithm looks at the K closest data points to a new sample and assigns the most common class among those neighbors.

Example: K = 3 Neighbors: Class A Class A Class B Prediction = Class A

3. Steps of KNN Algorithm

  1. Choose the number of neighbors (K).
  2. Calculate the distance between the new data point and all training data.
  3. Select the K nearest neighbors.
  4. Count the classes of the neighbors.
  5. Assign the majority class as the prediction.

4. Distance Calculation

Euclidean Distance

Distance = √((x2 - x1)² + (y2 - y1)²)

This is the most commonly used distance method in KNN.

5. Types of KNN

  • Classification KNN – Output is a category.
  • Regression KNN – Output is a numerical value.

6. Advantages

  • Simple and easy to understand
  • No training phase required
  • Works well with small datasets
  • Easy to implement

7. Disadvantages

  • Slow for large datasets
  • Requires choosing the correct value of K
  • Sensitive to noise in data
  • High memory usage

8. Applications

  • Recommendation systems
  • Pattern recognition
  • Image classification
  • Medical diagnosis
  • Spam detection
