Process Management

Operating System Concept

1. What is a Process?

A process is a program that is currently being executed by the computer. When a program is stored on disk it is just a passive entity, but when it is loaded into memory and executed by the CPU it becomes a process.

The operating system is responsible for managing multiple processes efficiently so that the CPU can execute tasks smoothly.

Example: When you open Google Chrome, Microsoft Word, or a music player, each application runs as a separate process in the operating system.

2. Characteristics of a Process

  • Each process has a unique Process ID (PID)
  • Processes run independently
  • Each process requires memory and CPU resources
  • The OS controls the execution of processes

3. Process States

A process moves through different states during its life cycle.

  • New – Process is being created.
  • Ready – Process is waiting for CPU allocation.
  • Running – Process is currently being executed.
  • Waiting – Process is waiting for I/O operation.
  • Terminated – Process has finished execution.

4. Process Control Block (PCB)

The Process Control Block is a data structure used by the operating system to store information about a process.

Each process has its own PCB which helps the operating system manage the process effectively.

Information stored in PCB:

  • Process ID
  • Process state
  • CPU registers
  • Memory management information
  • Scheduling information
  • I/O status

5. Context Switching

Context switching occurs when the CPU switches from one process to another. During this process, the state of the current process is saved in the PCB and the state of the next process is loaded.

Example: While playing music and browsing the internet at the same time, the CPU rapidly switches between processes to give the illusion that both tasks are running simultaneously.

6. Interprocess Communication (IPC)

Processes sometimes need to communicate with each other to share data. This communication is known as Interprocess Communication.

Methods of IPC:

  • Shared Memory
  • Message Passing
  • Pipes
  • Sockets

IPC is important for synchronization and data sharing between processes.

7. Advantages of Process Management

  • Improves CPU utilization
  • Supports multitasking
  • Ensures smooth execution of programs
  • Allows multiple applications to run simultaneously
